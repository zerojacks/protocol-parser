# 附录H（规范性附录）中继转发

> 来源：Q/CSG1209022-2019《计量自动化终端上行通信规约》

- 附录H
（规范性附录）
中继转发

- H.1　中继数据标识编码

数据标识编码格式都按如下定义，见表H.1：

	表H.1　数据标识编码

| 数据标识编码 | 下行数据格式 | 字节数 | 上行数据格式 | 字节数 |
| --- | --- | --- | --- | --- |
| DI3 | DI2 | DI1 | DI0 |  |  |  |  |
| E3 | 02 | 00 | 01 | 中继类型（1字节） | L+8 | 中继类型（1字节） | L+2 |
|  |  |  |  | 端口号（1字节） |  | 中继报文长度（1字节，L） |  |
|  |  |  |  | 通信波特率（1字节） |  |  |  |
|  |  |  |  | 校验方式（1字节） |  |  |  |
|  |  |  |  | 数据位（1字节） |  | 中继报文 |  |
|  |  |  |  | 停止位（1字节） |  |  |  |
|  |  |  |  | 超时时间（1字节，秒） |  |  |  |
|  |  |  |  | 中继报文长度（1字节，L） |  |  |  |
|  |  |  |  | 中继报文 |  |  |  |

中继类型：00表示普通中继；01表示转发主站对电能表的拉闸命令；02表示转发主站对电能表的允许合闸命令；03表示转发主站对电能表的保电投入命令；04表示转发主站对电能表的保电解除命令。

端口号定义参见数据标识编码E080000AH的定义；通信波特率，校验方式，数据位，停止位的定义参见数据标识编码E080000BH的定义。

中继转发命令可以转发主站直接对电能表的抄读命令，对电能表的遥控跳闸/允许合闸命令，对电能表的遥控送电命令等等。
