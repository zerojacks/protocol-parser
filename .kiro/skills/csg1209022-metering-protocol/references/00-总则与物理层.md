# 总则与物理层

> 来源：Q/CSG1209022-2019《计量自动化终端上行通信规约》

- 范围

本标准规定了计量自动化系统主站和终端之间进行数据传输的帧格式、数据编码及传输规则。

本标准适用于点对点、多点共线及一点对多点的通信方式，适用于主站对终端执行主从问答方式以及终端主动上传方式的通信。

本标准规定厂站电能量采集终端、负荷管理终端、配变监测计量终端、低压电力用户集中抄表系统集中器等计量自动化终端与主站的通信规则。

- 术语、定义和缩略语

- 术语和定义

- 终端地址  terminal address

系统中终端设备的地址编码，简称终端地址。

- 系统广播地址  system broadcast address

系统中所有终端都应该响应的地址编码。

- 主站地址  master station address

主站中具有通信需求的对象（如工作站、应用功能模块等）的编码。

- 前置机 front end processor

负责通过各种通信介质和终端进行通信的前置设备，并能在主站其他部分脱离联系后（通讯部分还正常），维持系统运行的设备。

- 测量点  measured point

指可以测量出唯一的一组电气量值的测量装置与终端的顺序电气连接点，当物理上相同的一个电气连接点被多个装置所测量，或者被一个装置所测量但通过多种方式被传递到终端时，按照多个测量点计，每个测量点具有唯一的逻辑定位编码，是该装置在终端的参数配置、数据应用的唯一对象标识。

- 信息点  information point

表示参数或数据的对象信息，如测量点、控制轮次、直流模拟量分路等。

- 任务  task

规定终端在指定时间或条件下执行所需的操作序列。

- 中继命令forward

终端将收到的中继命令中的中继报文内容不做任何解释发给下属设备，然后将下属设备返回的结果不加任何解释封装到中继命令返回结构中。

- 中继任务 forward task

规定终端在指定时间执行的中继命令，命令在任务中指定，结果由终端保存后返回到主站。

- 通信流量  communication flow

指由终端以本数据传输协议完整报文帧为基础统计的，与主站间的接收与发送报文帧的累计字节数。

- 规约版本号 protocol version

规约版本号表示本规约文本当前的版本号。本规约每次修订都需要更改规约版本号。

- 消息认证码　message authentication code（MAC）

为保证消息数据的完整性，由密钥对消息数据进行运算后产生的代码。。

- 物理层

- 　TCP和UDP的传输接口

该类接口的登录链接和心跳检测采用链路测试服务，链路测试周期可设定。

参见TCP/IP协议规范。

- 　串行通信传输接口

字节传输按异步方式进行，它包含8个数据位、1个起始位“0”、1个偶校验位P和1个停止位“1”，定义见图4-1：

- 　红外通信传输接口

采用红外通信方式实现本地数据传输时，字节格式与串行通信传输格式相同，在发送数据时，在有效数据帧前加1~4个FEH作为前导码。

- 　PSTN通信传输接口

话音MODEM需支持CCITT V.22bis、V.32bis、V.34、V.90、V.92标准协议，支持V.42、MNP等纠错协议和V.42bis、MNP5等数据压缩协议，通信速率支持1200bps~56kbps。

- 　音频专线通信传输接口

音频专线MODEM支持V.23标准，中心频率为1700Hz，发送“1”，频率为1300Hz，发送“0”，频率为2100Hz，通信速率为300bps~1200bps。
