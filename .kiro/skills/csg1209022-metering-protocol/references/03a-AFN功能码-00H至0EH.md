# 应用层 AFN 功能码（00H~0EH）

> 来源：Q/CSG1209022-2019《计量自动化终端上行通信规约》

## 本节目录

- 确认∕否定（AFN=00H）
- 链路接口检测（AFN=02H）
- 写参数（AFN=04H）
- 安全认证（AFN=06H）
- 读参数（AFN=0AH）
- 读当前数据（AFN=0CH）
- 读历史数据（AFN=0DH）
- 读事件记录（AFN=0EH）

- 　确认∕否定（AFN=00H）

		#### 6.2.1.1　报文格式

确认∕否定报文是对接收报文中需要被确认（CON=1）的回答，以及终端对所请求的数据不具备响应条件的否定回答。该报文为单帧报文，帧序列域的标志位FIR=1，FIN=1，CON=0。格式见图6-7：

| 68H |  |
| --- | --- |
| L |  |
| L |  |
| 68H |  |
| C |  |
| A |  |
| AFN=00H |  |
| SEQ |  |
| 信息点标识1 |  |
| 数据标识编码1 |  |
| 数据标识内容1 | 00：表示确定 01：表示否定 |
| …… |  |
| 信息点标识1 |  |
| 数据标识编码m |  |
| 数据标识内容m |  |
| 信息点标识n |  |
| 数据标识编码1 |  |
| 数据标识内容1 |  |
| …… |  |
| 信息点标识n |  |
| 数据标识编码m |  |
| 数据标识内容m |  |
| CS |  |
| 16H |  |

图6-7　确认/否定报文格式

		#### 6.2.1.2　信息点标识定义

信息点标识定义见6.1.3。

		#### 6.2.1.3　数据标识编码定义

数据标识编码定义见6.1.4。

若数据标识编码为E0000000H，则表示进行全部确认/否认应答，数据格式见A.1。

		#### 6.2.1.4　数据标识内容定义

数据标识内容定义见6.1.5。

全部确认/否认报文帧格式为：

| 68H |  |
| --- | --- |
| L |  |
| L |  |
| 68H |  |
| C |  |
| A |  |
| AFN=00H |  |
| SEQ |  |
| 信息点标识=0000H |  |
| 数据标识编码=E0000000H |  |
| 数据标识内容 | 00：表示确定 01：表示否定 |
| CS |  |
| 16H |  |

在确认链路接口检测、身份认证及密钥协商、任务主动上送报文、告警主动上送报文时，使用本帧报文进行确认或否认。

- 　链路接口检测（AFN=02H）

本报文用于交换网络的数据传输信道，如GPRS/CDMA/3G/4G/以太网等，具有3个功能：终端登录网络、终端退出已登录的网络、终端保持在网的心跳。

| AFN=02H |
| SEQ |
| 信息点标识（DA=0） |
| 数据标识编码 |
| 数据标识内容 |
| CS |
| 16H |
