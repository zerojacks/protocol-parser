# 附录E（规范性附录）事件记录

> 来源：Q/CSG1209022-2019《计量自动化终端上行通信规约》

- 附录E
（规范性附录）
事件记录

- E.1　事件记录标识编码

抄读事件记录时，如果事件已发生，尚未恢复，例如失压记录，则其结束时间用FF填充，增量数据也用FF填充。抄读编程日志命令，每一应答帧只需表示同一个时间点设置的数据。

- E.2　事件记录的数据内容

表E.2　事件记录的数据内容

| 编号 | 事件数据内容 |
| --- | --- |
| ERD1 | 编程时间（YYMMDDhhmmss） |
|  | 通信通道，参见主站通信地址中的通信通道类型 |
|  | 编程数据标识组数（BIN码，1字节） |
|  | 编程数据1标识编码（DI3DI2DI1DI0） |
|  | 编程后内容1 |
|  | …… |
|  | 编程数据n标识编码（DI3DI2DI1DI0） |
|  | 编程后内容n |
| ERD2 | 最大需量清零时间1（YYMMDDhhmmss） |
| ERD3 | 开始时间（YYMMDDhhmmss）4 |
|  | 结束时间（YYMMDDhhmmss）4 |
|  | 正向有功总电能量（DI3DI2DI1DI0=00010000H）增量4 |
|  | 反向有功总电能量（DI3DI2DI1DI0=00020000H）增量4 |
|  | 组合无功1总电能量（DI3DI2DI1DI0=00030000H）增量4 |
|  | 组合无功2总电能量（DI3DI2DI1DI0=00040000H）增量4 |
| ERD4 | 停电时刻（YYMMDDhhmmss） |
|  | 复电时刻（YYMMDDhhmmss） |
| ERD5 | 开始时间（YYMMDDhhmmss） |
|  | 结束时间（YYMMDDhhmmss） |
|  | A相电压偏差最大值（DI3DI2DI1DI0= E1000101H） |
|  | B相电压偏差最大值（DI3DI2DI1DI0= E1000102H） |
|  | C相电压偏差最大值（DI3DI2DI1DI0= E1000103H） |
|  | 频率偏差最大值（DI3DI2DI1DI0= E1000104H） |
|  | 电压不平衡度最大值（DI3DI2DI1DI0= E1000105H） |
|  | 短时闪变最大值（DI3DI2DI1DI0= E100010DH） |
|  | 长时闪变最大值（DI3DI2DI1DI0= E100010EH） |
|  | A相电压总畸变率最大值（DI3DI2DI1DI0= E100010FH） |
|  | B相电压总畸变率最大值（DI3DI2DI1DI0= E1000110H） |
|  | C相电压总畸变率最大值（DI3DI2DI1DI0= E1000111H） |
| ERD6 | 控制事件发生时间（YYMMDDhhmmss） |
|  | 控制事件类型（1：拉闸  2：合闸 3：保电 4：保电解除） |
|  | 正向有功总电能（DI3DI2DI1DI0=00010000H） |
|  | 反向有功总电能（DI3DI2DI1DI0=00020000H） |
| ERD7 | 消息认证错误发生时间（YYMMDDhhmmss） |
|  | 消息认证码PW |
|  | 启动站地址MSA |
| ERD8 | 参数变更发生时间（YYMMDDhhmmss） |
|  | 变更参数1标识编码（DI3DI2DI1DI0） |
|  | ……. |
|  | 变更参数n标识编码（DI3DI2DI1DI0） |
| ERD9 | 校时发生时间（YYMMDDhhmmss） |
|  | 正向有功总电能（DI3DI2DI1DI0=00010000H） |
|  | 反向有功总电能（DI3DI2DI1DI0=00020000H） |
| ERD10 | 恒定磁场干扰记录（DI3DI2DI1DI0=03350001H） |
|  | 开始时间（YYMMDDhhmmss） |
|  | 结束时间（YYMMDDhhmmss） |
|  | 发生时刻正向有功总电能 |
|  | 发生时刻反向有功总电能 |
|  | 结束时刻正向有功总电能 |
|  | 结束时刻反向有功总电能 |
| ERD11 | 负荷开关误动作记录（DI3DI2DI1DI0=03360001H） |
|  | 开始时间（YYMMDDhhmmss） |
|  | 结束时间（YYMMDDhhmmss） |
|  | 负荷开关误动作后状态 |
|  | 负荷开关误动作发生时刻正向有功总电能 |
|  | 负荷开关误动作发生时刻反向有功总电能 |
|  | 负荷开关误动作结束时刻正向有功总电能 |
|  | 负荷开关误动作结束时刻反向有功总电能 |
| ERD12 | 电源异常记录（DI3DI2DI1DI0=03370001H） |
|  | 开始时间（YYMMDDhhmmss） |
|  | 结束时间（YYMMDDhhmmss） |

|  | 电源异常发生时刻反向有功总电能 |
